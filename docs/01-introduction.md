# 01 Introduction

## What This Package Solves

SatisHub helps you sell private Composer packages with full license control.

After installing SatisHub, you can:

- create packages and products in an admin panel
- charge customers via Stripe, Polar, or LemonSqueezy
- generate and enforce license entitlements
- expose private repository metadata and dist files securely
- validate licenses in customer applications

## Who Uses It

- Vendor/owner: manages catalog, billing mappings, support, and license lifecycle.
- Customer: buys a product, receives a license, and installs package versions via Composer auth.

## What a Buyer Gets

When a user buys your plugin/product, they get:

- a license key
- activation/validation capability
- private package access bound to license status and support rules
- support traceability through order and ticket context
